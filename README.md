# Руководcтво пользователя #

**HotelARM** представляет собой специализированный программный комплекс, созданный для автоматизации ежедневных операций администратора и ведения учета гостиничного фонда. Данное решение позволяет организовать работу с постояльцами в рамках единого цифрового пространства.

## Предназначение проекта

Разработка HotelARM направлена на оптимизацию административных процессов и повышение точности ведения документации.

Приложение позволяет решать следующие задачи:  
•   централизованное хранение информации о номерном фонде;  
•   оперативный поиск сведений по активным бронированиям;  
•   исключение ошибок при регистрации новых клиентов;  
•   удобное планирование трудовой деятельности сотрудников.  

---

## Функциональные возможности

•   регистрация новых объектов системы (карточки гостей, описания номеров);  
•   мониторинг текущего состояния комнат в реальном времени;  
•   корректировка персональных данных постояльцев;  
•   изучение показателей эффективности через блок аналитики;  
•   просмотр графика смен для технического отдела;  
•   автономная работа с данными без доступа к интернету;  
•   интуитивно понятная навигация между разделами.  

---

## Технологический стек

•   **Язык программирования:** C#  
•   **Используемая платформа:** .NET Framework 4.8  
•   **Архитектура приложения:** Desktop (Windows Forms)  
•   **Инструментарий разработки:** Visual Studio 2022  
•   **Механизм хранения данных:** Система SQLite  

---

## Инструкция по запуску

1.  Выполните загрузку исходного кода из репозитория.  
2.  Разместите файлы проекта в выбранной директории.  
3.  Запустите основной файл проекта с расширением **.sln** через Visual Studio.  
4.  Проведите сборку решения для подгрузки необходимых библиотек.  
5.  Используйте клавишу **F5** для старта программного модуля.  

---

## Эксплуатация системы

После инициализации программы пользователю доступны следующие действия:  
•   авторизация в персональном кабинете сотрудника;  
•   внесение свежих записей о заселении в отель;  
•   просмотр архивных данных о прошлых визитах;  
•   обновление технических характеристик номерного фонда;  
•   удаление устаревших или ошибочных записей;  
•   полный контроль операционной деятельности отеля.  

---

## Состав программного решения

•   **Forms/** — визуальные компоненты и окна взаимодействия.  
•   **Data/** — программная логика для связи с базой данных.  
•   **Models/** — описание ключевых сущностей (Номера, Клиенты).  
•   **my_database.db** — файл локального хранилища информации.
