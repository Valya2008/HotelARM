# 8. Макетирование интерфейса пользователя
Проектирование интерфейса АРМ администратора отеля основывалось на принципах минимализма, высокой информативности и скорости выполнения задач. 

Для иллюстрации были созданы макеты ключевых экранов, отражающие их функционал и логику взаимодействия.

 1. Экран авторизации (FormLogin)  
•  Назначение: Первичная идентификация пользователя.  
•  Элементы: Поля для ввода логина и пароля, кнопка "Войти".  
•  Макет:

### 2. Главное меню (FormMenu)  
•  Назначение: Центральный узел навигации. Динамически отображает кнопки доступа к модулям.  
•  Элементы: Кнопки навигации (Гости, Номера, Бронирования, Аналитика, График персонала, Тех. персонал), индикатор текущей роли пользователя.  
•  Макет:

### 3. Список гостей (FormGuests)
•  Назначение: Отображение всех зарегистрированных гостей.  
•  Элементы: Таблица DataGridView с данными (ФИО, телефон), строки поиска, кнопки "Добавить", "Редактировать", "Удалить".

•  Элементы: Поля с персональными данными (ФИО, паспорт, телефон, email, адрес), кнопка "Сохранить", "Отменить".
