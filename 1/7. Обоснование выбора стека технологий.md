# Обоснование выбора стека технологий

Для разработки АРМ администратора отеля был выбран современный и надежный стек технологий, обеспечивающий высокую производительность и стабильность работы в локальной среде.
 
### 1. Язык программирования
---
**C#** выбран в качестве основного языка разработки по следующим причинам:

•   **Стандарт индустрии:** Он считается ведущим инструментом для создания корпоративного и прикладного софта под управлением ОС Windows.
•   **Строгая типизация:** Эта особенность минимизирует вероятность логических ошибок при написании кода и упрощает управление объектами (Гости, Номера, Бронирования).
•   **Производительность:** Глубокая интеграция с платформой .NET Framework гарантирует моментальный отклик интерфейса, что важно для комфортной работы персонала.

### 2. Фреймворк и графический интерфейс
---
В качестве платформы разработки используется **Windows Forms (.NET Framework 4.8)**.

**Обоснование выбора:**

•   **Скорость разработки UI:** Встроенный визуальный конструктор позволяет оперативно проектировать сложные формы с помощью стандартных компонентов Windows.
•   **Стабильность:** Технология WinForms проверена временем и гарантирует корректное отображение элементов интерфейса на большинстве рабочих станций.
•   **Низкие системные требования:** Приложение потребляет мало ресурсов, потому оно стабильно работает даже на слабых офисных компьютерах.
•   **Нативная интеграция:** Программа обладает полной совместимостью с Windows 10 и Windows 11 без установки лишних компонентов.

### 3. Система управления базами данных (СУБД)
---
В данной системе используется **SQLite**.

**Преимущества SQLite для данного проекта:**

•   **Автономность:** База данных функционирует без установки сервера. Весь массив информации хранится в одном файле, который максимально просто переносить или копировать.
•   **Реляционная структура:** Позволяет выстраивать сложные связи между таблицами, например, объединять данные о госте с его историей проживания.
•   **Использование SQL:** Технология дает возможность выполнять глубокие аналитические запросы, которые невозможно реализовать в простых текстовых файлах.
•   **Целостность данных:** Поддержка механизма внешних ключей гарантирует защиту записей от повреждения при удалении связанных элементов.

### 4. Инструменты тестирования
---
Для проверки корректности работы программного обеспечения используются:

•   **Тест-кейсы:** Проверочные сценарии, которые строятся на базовых вариантах эксплуатации системы.
•   **Функциональное тестирование:** Ручная проверка всех возможностей приложения на предмет соответствия требованиям.

Данный подход является достаточным для локального приложения и позволяет верифицировать работу каждой ключевой функции.

### 5. Вывод
---
Выбранный технологический стек (**C#, WinForms, SQLite**) признан оптимальным для создания локального автоматизированного рабочего места. 
Данная связка гарантирует баланс между скоростью разработки, защитой персональных данных и удобством сопровождения продукта.
