# Описание прецедентов #
 Прецедент №1: Аутентификация пользователя ###

| Раздел | Описание |
| --- | --- |
| ID | UC-01 |
| Название | Аутентификация пользователя в системе |
| Цель | Получить безопасный доступ к функционалу АРМ согласно роли (Администратор или Тех. персонал). |
| Актор | Администратор / Тех. персонал |
| Предварительные условия | 1. Приложение запущено.&#10; &#10;  
2. В базе данных SQLite существуют учётные записи пользователей. |
| Основной поток | 1. Пользователь вводит Логин и Пароль.&#10; &#10;  
2. Система проверяет данные в таблице Users.&#10; &#10; 3. При совпадении данных определяется роль (Admin/TechStaff).&#10; &#10; 4. Открывается главное меню с набором функций, доступных для этой роли. |
| Исключения | • Неверные данные: Вывод ошибки «Неверный логин или пароль».&#10; &#10;  
• Пустые поля: Блокировка входа до заполнения всех полей. |
| Постусловия | Пользователь авторизован и получил доступ к интерфейсу согласно своим правам. |
