# Описание прецедентов #
 Прецедент №1: Аутентификация пользователя ###

| Раздел       | Описание                                                                 |
|--------------|--------------------------------------------------------------------------|
| **ID**       | UC-01                                                                    |
| **Название** | Аутентификация пользователя в системе                                    |
| **Цель**     | Получить безопасный доступ к функционалу АРМ согласно роли (Администратор или Тех. персонал) |
| **Актер**    | Администратор / Тех. персонал                                            |
| **Предварительные условия** | 1. Приложение запущено.  
2. В базе данных SQLite существуют учетные записи пользователей. |
| **Основной поток** | 1. Пользователь вводит Логин и Пароль.  
2. Система проверяет данные в таблице Users. 3. При совпадении данных определяется роль (Admin/TechStaff).  
4. Открывается главное меню с набором функций, доступных для этой роли. |
| **Исключения** | - Неверные данные: вывод ошибки «Неверный логин или пароль». - Пустые поля: блокировка входа до заполнения всех полей. |
| **Постусловия** | Пользователь авторизован и получил доступ к интерфейсу согласно своим правам. |
