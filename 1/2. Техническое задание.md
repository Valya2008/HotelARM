# Техническое задание

### 1. Общие сведения
Программный продукт «Автоматизированное рабочее место (АРМ) администратора отеля» разрабатывается для автоматизации учета и управления номерным фондом, гостями, бронированиями и персоналом отеля.
Приложение предназначено для локальной работы на ПК под управлением ОС Windows.

### 2. Цели и задачи создания системы  
**Цель:** Повышение эффективности работы персонала отеля за счет автоматизации рутинных операций, исключения человеческого фактора при планировании и улучшения качества обслуживания гостей.  

**Задачи:**  
•   Обеспечение централизованного хранения данных в СУБД SQLite.
•   Переход от бумажного учета (или табличного) к цифровому.
•   Реализация ролевой модели доступа: "Администратор" и "Тех. персонал".
•   Автоматизация учета гостей, номеров и бронирований.
•   Предоставление аналитики и статистики для принятия управленческих решений.

### 3. Целевая аудитория
1.  **Администраторы:** Сотрудники, ответственные за регистрацию гостей, управление номерами, бронированиями, персоналом и аналитикой.
2.  **Тех. персонал (Уборщики, Ремонтники):** Сотрудники, которым необходим доступ только к своему графику работы для выполнения текущих задач.

### 4. Общие требования
•   **Технические:** Приложение должно быть реализовано на языке C# (WinForms) с использованием .NET Framework.  
•   **Эксплуатационные:** Система должна функционировать без доступа к интернету.  
    Интерфейс должен быть адаптирован для быстрой работы через интуитивно понятную навигацию.  

### 5. Основные характеристики системы:
•   все данные хранятся в локальной базе данных **SQLite**;  
•   доступ к функциям зависит от роли пользователя, определенной при авторизации;  
•   пользовательский интерфейс включает формы для:  
    •   учета гостей и технического персонала;  
    •   управления номерами и бронированиями;  
    •   просмотра графика персонала;  
    •   визуализации аналитики и текущей загрузки отеля.
